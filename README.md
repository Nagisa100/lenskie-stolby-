# Хранители Столбов

## Кейс 7. Компьютерная игра по растениям нацпарка «Ленские столбы»

Хранители Столбов — компьютерная игра, в которой ты играешь за рейнджера природногопарка «Ленские столбы». Патрулируй тропу вдоль Лены, следи за туристами, спасай растенияиз Красной книги и собирай энциклопедию из 27 видов.

### Описание проекта

* 27 видов растений, кустарничков, грибов и мхов нацпарка «Ленские столбы»
* 6 зон карты: Берег Лены, Тукулан, Кордон, Тайга, Засуха, Луга и Посёлок
* Энциклопедия с фактами о каждом виде из Красной книги
* Туристы-нарушители: мусорят, срывают растения - уговори их или наведи порядок
* Сбежавшие лошади с фермы: поймай и отвези к воротам
* Очки SAVE / LOST / XP, миникарта и статистика

### Технологии

* Python 3
* pygame-ce - игровое окно, ввод, звук
* Pillow - вся графика игры
* Тайлсет Kenney Tiny Town сами, доработали и пересобрали с помощью ии и получили свой вариант

### Установка
Требуется Python 3.10 или новее.
* Склонируй репозиторий:
git clone https://github.com/Nagisa100/lenskie-stolby-
* Установи зависимости:
pip install -r requirements.txt

### Запуск

python main.py
